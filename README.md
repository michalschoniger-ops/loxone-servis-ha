# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 3.0.69 přidává v Evora Smart Menu 3.0.46 ruční založení Miniserveru buď v Hubu, nebo pouze v macOS Klíčence. Po připojení určí skutečný model z oficiálního `msInfo.miniserverType`, automaticky přiřadí fotografii a lokální záznam lze později synchronizovat do Hubu. Zachovává také vycentrovanou kartu Partner Coache s fotografií a kontakty, aktuální Stable, Beta a Alpha verzi Configu přes Windows Launcher 3.0.0.13, Windows Menu 3.0.34, technické macOS Menu 3.0.35 a databázové schéma 27.
