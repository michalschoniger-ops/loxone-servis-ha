# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 3.0.76 přináší Evora Smart Menu 3.0.52 s úplným vyhledáváním rychlých voleb po kliknutí pravým tlačítkem a běžným odstupem nabídky pod horní lištou macOS. Připnout lze konkrétní Miniserver, celou sekci nebo jednotlivé funkce Intranetu a konkrétní osobní poznámku s obsahem v bočním podmenu. Hub sjednocuje pražskou provozní dobu podpory pro profil Partner Coache a při dočasném timeoutu Loxone Portálu zachová poslední ověřenou cache ticketů. Zachovává dvanáctiměsíční docházku, přímou rezervaci zasedaček, objednávky, školení, dostupné faktury, ruční Miniservery, Launcher 3.0.0.16, Windows Menu 3.0.34, technické macOS Menu 3.0.35 a databázové schéma 27.
