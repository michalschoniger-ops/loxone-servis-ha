# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 3.0.68 zpřesňuje historii školení podle aktuálního LOXONE Portálu, načítá Partner Coache včetně chráněné fotografie a kontaktů a vydává Menu aktuální Stable, Beta a Alpha verzi Configu. Evora Smart Menu 3.0.45 má Coachovu velkou kulatou fotografii vycentrovanou nad jménem, rolí a kontakty, nedostupné volitelné části Portálu vůbec nezobrazuje a stažení Configu předává výhradně Windows Launcheru 3.0.0.13. Windows Menu zůstává 3.0.34 a technické macOS Menu 3.0.35; databázové schéma je 27.
