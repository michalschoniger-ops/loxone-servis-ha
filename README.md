# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 3.0.7 dokončuje kontrastní audit tmavého režimu v navigaci, kartách, tabulkách, formulářích, modalech, ticketech, úkolech, Intranetu, diagnostice, zálohách i mobilní nabídce. Pomocné texty, placeholdery, zakázaná a automaticky doplněná pole i barevné datové stavy mají vlastní čitelné tmavé varianty kontrolované automatickým WCAG AA testem. Evora Smart Menu a Windows klient zůstávají ve verzi 3.0.1, Config Launcher ve verzi 3.0.0.2. Všechna data, importované úkoly a šifrovaná připojení zůstávají zachovaná.
