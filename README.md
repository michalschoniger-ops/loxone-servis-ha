# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 2.2.5 rozšiřuje správcovský Intranet o kontakty a žádosti o dovolenou či absenci. Postranní nabídka má barevně odlišené buňky, Intranet vlastní zelenou ikonu „e“ a tabulka uživatelů kompaktní řádky. Hub i Evora Smart Menu 5.8.5 mají globální hledání v celé nabídce včetně podsložek; Smart Menu zároveň zachovává živý čas a jasný stav sledování bez rušivého počtu upozornění. Všechna data a šifrovaná připojení zůstávají zachovaná.
