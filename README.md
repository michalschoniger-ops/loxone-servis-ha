# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 3.0.74 přináší Evora Smart Menu 3.0.50 s vyhledávanými rychlými volbami po kliknutí pravým tlačítkem. Připnout lze konkrétní Miniserver pro Loxone Config, Loxone App nebo správu přístupů i vybrané funkce Menu. Historie docházky drží dvanáct měsíců a měsíční souhrny; rezervace zasedaček je znovu přímo v nativním menu. Zachovává horní profil Partner Coache, dostupné části objednávek, školení a faktur, ruční Miniservery, Launcher 3.0.0.16 se stahováním Configu přímo do Windows bez Edge, Windows Menu 3.0.34, technické macOS Menu 3.0.35 a databázové schéma 27.
