# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 3.0.6 přidává v Nastavení volbu Světlý, Tmavý a Automaticky podle zařízení. Tmavý režim mění všechny povrchy Hubu včetně navigace, karet, tabulek, formulářů, modalů, ticketů, úkolů, Intranetu, diagnostiky a mobilní nabídky. Současně zůstává správa uživatelů na desktopu v jednom kompaktním řádku a přibývá chráněný prvotní import XLSX. Evora Smart Menu a Windows klient zůstávají ve verzi 3.0.1, Config Launcher ve verzi 3.0.0.2. Všechna data a šifrovaná připojení zůstávají zachovaná.
