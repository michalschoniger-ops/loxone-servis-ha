# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 3.0.51 dává plnému macOS Menu 3.0.35 dvě samostatná tlačítka: originální LOXONE znak pro Podporu/Váchu a zelený WhatsApp glyph pro Filipa Kubína, Lukáše Majera a Jiřího Vaverku. Všechny volby používají přímé nativní odkazy `whatsapp://`, takže Mac neotevře mezistránku v Safari. Není-li aplikace nainstalovaná, Menu zobrazí chybu a web samo neotevře. Osobní párování, Windows Menu 3.0.31, ruční kontrola flotily, technické macOS Menu 3.0.35 a databázové schéma 24 zůstávají zachované.
