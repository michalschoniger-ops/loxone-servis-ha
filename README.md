# EVORA Smart Hub pro LOXONE a Home Assistant

Veřejný instalační katalog pro Home Assistant. Obsahuje jen instalační metadata a hotový aplikační runtime, ze kterého Home Assistant sestaví lokální obraz. Neobsahuje hesla, databáze ani zákaznické údaje. HA Práce lze provozovat jako jediný hlavní server a HA Domov jako bezstavového klienta, takže obě instalace i veřejný HTTPS odkaz používají stejná aktuální data.

Verze 2.2.0 přidává správcovskou integraci **Evora Intranet** s běžícím časem docházky, historií aktuálního a předchozího měsíce, přehledem kolegů a potvrzovanými docházkovými akcemi. Mobilní menu nyní obsahuje jediný viditelný odchod z účtu, podporu uvnitř LOXONE a provozní log, uživatele i nástroje pod Nastavením. Čtyři hlavní akce Miniserverů mají sjednocené buňky, vlastní ikony a bezpečné zalamování. Součástí je WorkLogAI 5.8.2 a nový samostatně ověřovaný Keychain helper; uložená data zůstávají zachována.
